# Lint And Test

검증은 변경 범위에 맞게 최소한으로 수행한다.

- 가능한 경우 빌드, 테스트, 린트, 타입체크 중 관련 명령을 실행한다.
- 사용자가 무검증 브랜치 push 모드를 명시한 경우 빌드, 테스트, 린트, 타입체크를 생략하고 push할 수 있다.
- 무검증 브랜치 push 모드에서 생략한 검증은 `미검증 - 사용자 요청에 따른 무검증 push`로 보고한다.
- 문서만 수정했다면 빌드/테스트 생략 가능하되 이유를 적는다.
- 실행한 명령과 결과를 짧게 보고한다.
- 실패하면 핵심 에러와 다음 확인 방법을 적는다.
- 실행하지 못한 항목은 `미검증`으로 표시한다.
- 테스트하지 않은 기능을 정상 동작한다고 말하지 않는다.
